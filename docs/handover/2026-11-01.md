## Notes for whoever is next

- `Figure3D` has no crouch clip: "sit" at 0.17 is a good crouch (hands low,
  knees bent); "lift" at 0.42 is only a slight bend, for things at table height.
- `{"theme": [...]}` in a talk tree plays the first track the game has; with
  none, the music doesn't change.
- `AshfordLife` runs while nobody's in a scene; scenes that move people stop
  it for them (`_free`).
